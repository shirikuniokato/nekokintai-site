# ねこ勤怠 LP 2.1.0 更新仕様

## 方針

- LPタイプ: Type A（スマホアプリ）
- 既存のドット絵とやわらかい日本語を維持し、2.1.0の新機能を追加する
- 常設コピーではBGMの曲数を固定せず、バージョン履歴だけ3曲と記載する
- iOS / Androidのストアバッジを主CTAとして維持する

## 更新内容

1. メタ説明に作業用BGMを追加する
2. 特徴欄に「いろんなねこ」「作業用BGM」を追加する
3. ホーム画面を、しろねことBGMボタンが見える2.1.0の実画面へ差し替える
4. ねこ屋さんの実画面を追加し、ねこの追加と並べ替えを紹介する
5. ロードマップのiOS / Android先頭に2.1.0の審査中カードを追加する
6. 2.1.0で実現した「新しいねこ」を将来案から外す
7. よくある質問から解消済みの不具合案内を削除し、現行の操作説明へ更新する
8. ロードマップの将来案を、現行実装と現在の要望に合わせて具体化する

## 公開条件

- `update.json` はストアで2.1.0が公開されるまで変更しない
- `npm test` と `npm run build` を通す
- PC幅とスマートフォン幅の実レンダリングを確認してから公開する
