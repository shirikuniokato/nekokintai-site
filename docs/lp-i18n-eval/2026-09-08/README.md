## 逆翻訳で見つかった取りこぼし（重要）

`upcoming2Question` の日本語を統合で「曜日ごと」→「曜日ごと・週ごと」に広げたのに、
**翻訳し直すキーの一覧から漏れていた**。3言語とも「曜日ごと」だけの古い訳が残り、
`check:i18n` は改行数と日本語混入しか見ないので通過してしまっていた。

再発防止として、日本語を変えたあとは次を必ず回す（`check:i18n` では拾えない）:

```sh
# 「日本語が変わったのに他言語が以前のまま」のキーを出す
python3 - <<'PY'
import json, subprocess
old=json.loads(subprocess.run(['git','show','HEAD:assets/qa/locales.json'],capture_output=True,text=True).stdout)
new=json.load(open('assets/qa/locales.json',encoding='utf-8'))
for k in new['ja']:
    if old['ja'].get(k)!=new['ja'][k]:
        for l in ('en','ko','zh-TW'):
            if k in old.get(l,{}) and old[l][k]==new[l].get(k): print(l,k)
PY
```

初稿の zh-TW は「曜日ごと」を `每天`（毎日）と訳していたため、`想依星期幾、依週設定更詳細的目標` に直した。
