# トップLP以外の全ページの翻訳監査 2026-09-04

`/tip/`（25文言）、`/qa/`（141文言）、`/roadmap/`（99文言）、`/contact/`（35文言）、`/privacy/`（46文言）を、英語・韓国語・台湾向け繁体字中国語へローカライズした記録。トップLPと同じ手順（`launch/lp-i18n-workflow-2026-09-01.md`）で、スクリプトは `--page <page>` で対象を切り替えた。

## ロードマップ・ごようぼう・プライバシーポリシー（同日 追加分）

- 初稿は Gemini（`*-gemini-initial.json`）、監査は Fable と GPT（`*-audit-*.json`）、採用と手直しは `*-adopted.json`、逆翻訳は `*-reverse-japanese-final.json`。
- **ごようぼう**: Fable 4件・GPT 2件、critical なし。韓国語のメールアドレス直後の助詞（「주소로」で回避）、英語の返信案内の矛盾、英語の FAQ 誘導文の断片、韓国語の選択肢の用語揺れを採用。逆翻訳監査は指摘なし。`<select>` の `value` は件名の仕分けに使うので日本語のまま、表示だけ翻訳。
- **プライバシーポリシー**: Fable 9件・GPT 15件。high は英語・韓国語の「正文は日本語版」の1文が「原文」の意味にとどまっていた点で、GPT の置換文（authoritative／기준으로）を採用。ほかは文書名・保存先・ラベルの用語揺れと台湾向け語彙（個人資料・選填・資料接收方）。「正文は日本語版」の1文は今回 4言語すべてに新しく足した。逆翻訳監査は指摘なし。
- **ロードマップ**: Fable 37件・GPT 33件、critical なし。high は「海外のストア」が読者の国基準で反転する点（3言語とも「日本以外のストア」に）、韓国語で「打刻」が「記録」に薄まる点、設定名・ボタン名の揺れ。用語揺れは監査の置換文ではなくアプリ 2.3.0 のロケールの文言（1日の切り替え時刻＝Start time for a new day、休憩にさそう時間＝Time before a break invitation、ねこ屋さん＝Cat shop など）に一括置換し、ふわしろ・ふわくろ・こげふわのねこの名前もアプリの表記に合わせた。一人称は I／我 に統一。逆翻訳監査は medium 2件（「表示時間を短くそろえ」の「そろえ」）を手直し。cron の同期スクリプト（`scripts/lib/roadmap-release.mjs`）は、状態チップと公開文を翻訳キー付きで書き換えるよう直し、キーのない古い HTML にはキーを持ち込まないことをテストで確かめた。
- 「そのさき やりたいこと」から「日本語いがいの言葉に対応する」を外した（2.3.0 のカードと矛盾するため）。

## トップLP: Google Play の「準備中」（同日 追加分）

Google Play は日本のみ配信中なので、日本語以外の言語ではバッジの下に「準備中」のチップと1行の注を出し、リンクを外す（`playStoreSoonChip`、`playStoreSoonNote`）。バッジの画像そのものは変えない。訳は Gemini が LP 全体を再生成した初稿（`lp-gemini-initial.json`）からこの2キーだけを採用し、既存40キーは上書きしない（09-02 と同じやり方）。監査は `lp-audit-*.json`。Fable はこの2キーに指摘なし。GPT の medium 2件（韓国語・繁体字の注が「国や地域そのものが準備中」と読める）を採用した。既存40キーへの指摘は今回の対象外（再生成した初稿に対するもので、公開中の訳は変えていない）。

## QA の古い記述の直し（同日 追加分）

「ねこは、これから増えますか？」（2.1.0 は公開済みなので「なりました」「お迎えできます」に）と「海外のストアでも入れられますか？」（App Store は全地域、Google Play は日本のみ・ほかは準備中）の日本語を直し、変えた4キー（`upcoming3Answer` `upcoming3Note` `unlikely13Answer` `unlikely13Note`）だけを再翻訳した。初稿は `qa-gemini-second.json`、監査は `qa-audit-second-*.json`、採用は `qa-adopted-second.json`。両監査ともこの4キーへの指摘は繁体字の「サバトラ」の柄名だけで、アプリの表記「銀虎斑貓」に合わせた。韓国語の語尾は 해요체 にそろえた。トップLPの繁体字 `shopScreenAlt` もアプリの表記「貓咪小舖」に合わせた。

## 手順と結果

1. `gemini-3.1-pro-preview` が3言語の初稿を生成した（`tip-gemini-initial.json`、`qa-gemini-initial.json`）。QA は40文言ずつ4回に分け、改行数が原文と違ったキー（`investigating1NoteBeforeEmail`）だけ頼み直した。
2. Claude Fable 5 と GPT-5.6 Sol が独立監査した（`*-audit-claude-fable.json`、`*-audit-gpt.json`）。critical はなし。
   - tip: Fable 9件・GPT 3件。両者が high とした韓国語の店名「ｼﾁｬのねこ屋さん」の部分翻訳を筆頭に10件を採用。
   - qa: Fable 65件・GPT 44件。メールアドレス前の「to／寄到」欠落、リンク前後の空白と韓国語の助詞、設定名の揺れ、「くろねこ勤怠」の訳揺れ（ブランド名と同じく日本語表記に統一）、ねこの毛色名の誤りを中心に70件を採用。
3. 採用した指摘・手直し・用語の一括置換は `tip-adopted.json` / `qa-adopted.json` に残し、`npm run apply:lp-i18n:draft -- --page <page> <adopted.json>` で辞書へ反映した。
   - 画面名・ボタン名（「時間を直す」「ねこ屋さん」「1日のきりかえ時刻」「休憩にさそう時間」など）とねこの毛色名は、監査の置換文ではなく**アプリ 2.3.0 の実際のロケール**（`nekokintai/src/app/i18n/locales/`）の文言に置き換えた。例: ねこ屋さん＝Cat shop / 고양이 가게 / 貓咪小舖、1日のきりかえ時刻＝Start time for a new day / 하루가 바뀌는 시각 / 一天的切換時間。
   - 英語と繁体字で「We／我們」と「I／我」が混在していたので、作者ひとりの声（I／我）に統一した。
   - トップLPと共通のキー（見出し・フッターのリンク・「言語」）は LP の訳をそのまま使う（`SHARED_KEYS`、`npm run check:i18n` が一致を検査）。
4. 最終稿を日本語へ逆翻訳して原文と照合した（`tip-reverse-japanese-final.json`、`qa-reverse-japanese-final.json`）。
   - tip: critical / high なし。`note4`（いただいた分だけがんばります）の3言語が「支援額に応じて」の含みを弱めているという medium 3件は、初稿監査で取引的に聞こえない表現を選んだ結果なので採用しない。
   - qa: critical なし、high 1件・medium 9件。「これからのこと」が「Upcoming Features／앞으로의 계획／未來計畫」と実装予定のように読める点（3言語）、説明文の「これからやりたいこと」が計画に格上げされた点、「打刻」が clock in だけになった点、「別のアプリとして作りたい」の確度の揺れを手直しした（`qa-adopted.json` の `manual` 末尾）。「ハチワレ＝Black-cap」の指摘は、アプリ 2.3.0 が同じ英語名を使っているので採用しない。
5. 英語だけ、回答と注の `white-space` を `normal` にした。原文の位置で改行すると1語だけの行が目立つため。韓国語・繁体字は日本語と同じ改行位置で読めるのでそのまま。

## 日本語原文の変更

QA の「日本語いがいの言葉にも対応してほしい」の答えは「今は日本語だけです」のままだと翻訳した先で矛盾するため、2.3.0 で英語・한국어・繁體中文に対応する旨（ロードマップの 2.3.0 カードと同じ内容）に書き換えた。ほかの古い記述（2.1.0 のねこの数など）は触っていない。

## 機械検査

`npm run check:i18n` が3ページぶんのキーの完全一致、空文字、改行数、翻訳漏れの日本語（ブランド名・店名・「くろねこ勤怠」・不具合文字列「ねここここ」・言語名「繁體中文」は許可）、禁止語、韓国語の助詞併記、LP と共通のキーの一致を検査する。`npm run test:browser` は `/tip/` と `/qa/` でも言語ボタンのクリック切替と、LP 用の画面画像を取りに行かないことを Chromium で確かめる。
