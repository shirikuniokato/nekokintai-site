# LP 翻訳監査 2026-09-01

トップLPの日本語40文言を、英語・韓国語・台湾向け繁体字中国語へローカライズした記録です。

## 手順と結果

1. `gemini-3.1-pro-preview` が3言語の初稿を生成した（`gemini-initial.json`）。
2. Claude Fable 5 と GPT-5.6 Sol が、初稿を独立して監査した。重大・高優先度の指摘はなく、Fableは medium 4件、GPTは medium 9件を報告した（`audit-*.json`）。
3. 意味の保持、世界観、短いUIへの収まりを優先して11件を採用し、`assets/lp/locales.json` に反映した。
4. 最終稿を日本語に逆翻訳して原文と照合した。繁体字の「働いた事実」と英語の「達成感」で各1件の意味差を修正し、最終再監査では指摘0件となった（`reverse-japanese-final-final.json`）。

## 機械検査

`npm run check:i18n` は、40キーの完全一致、空文字、意図した改行、翻訳漏れの日本語、禁止語、韓国語の危険な助詞併記、固定用語を検査する。

公開前には、`nekokintai.dev/?lang=en`、`?lang=ko`、`?lang=zh-TW` を実ブラウザのPC幅・スマートフォン幅で確認する。日本語だけの遷移先は、各ロケール上で日本語ページである旨を表示する。
